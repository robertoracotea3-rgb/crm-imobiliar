# kiraimobiliare.ro

The public website of Kira Imobiliare (Next.js, deployed on Vercel), plus the agents' app served at app.kiraimobiliare.ro.

- Listings, the map pins and the "Adaugă anunț" requests come from the Kira Imobiliare CRM (PC and phone apps) through
  its Supabase database. Setup, environment variables and domains: [PUBLIC_SITE_SETUP.md](PUBLIC_SITE_SETUP.md).
- `public/aplicatie/` is generated by the CRM build (`mobile/build-mobile.ps1 -Site`); do not edit it by hand.

```bash
npm install
npm run dev      # http://localhost:3000 ; the app address locally: http://app.localhost:3000
npm run build
```
